# EveryInfra Research plugin

Cross-check current claims with EverySearch MCP. Compare original sources, preserve dates and scope, distinguish contradictions, and cite conclusions at the evidence strength.

This package contains only `everyinfra-crosscheck-research`. It is a skills-only plugin: configure the approved EveryInfra service connection in the host before using it. It does not install other skills, register a new MCP server or broaden API permissions.

A concise claim, scoped conclusion, supporting original links, relevant dates and an explicit uncertainty section. The workflow should make it possible for a reader to inspect why the conclusion follows.

- An unavailable or empty retrieval path is uncertainty, not proof that a claim is false.
- Independent mechanisms do not automatically mean independent publishers or underlying evidence.
- No guarantee that every current claim can be resolved, and no invented confidence percentage.

Repository documentation and installation guidance accompany the source checkout. Current API documentation: https://api.everyinfra.com/docs
